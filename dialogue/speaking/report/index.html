别从头讲到尾，
先说你的判断。

领导听汇报，是为了快速掌握情况并作出决策。你需要带来的不只是过程，还有判断、证据和可执行的下一步。

01 / BEFORE YOU REPORT

开口前，
先确定五件事。

汇报的质量大多在开口前就已经决定。同一件事，时机、对象和时长不同，信息的组织方式也应该不同。

01

心态

把汇报当作帮助决策，不是为自己辩解。

02

时机

越紧急、越可能扩大的问题，越要尽早报。

03

对象

根据对方关注结论、数据或细节的习惯调整详略。

04

时长

开头就告知大致需要多久，给对方稳定预期。

05

内容

准备观点、事实和建议，删掉与决策无关的过程。

02 / REPORT STRUCTURE

开头给预期，
主体给依据，
结尾要行动。

“观点—事实—建议”是主体的核心。开头和结尾则负责让汇报进入正确的时间与决策轨道。

OPEN / 开头

要求 + 来意 + 时长

“按照您上周的要求，我把项目进度梳理了一遍，想用五分钟汇报两个情况。”

BODY / 主体

观点 + 事实 + 建议

“我的判断是进度需要顺延三天。目前两项关键数据未到位，测试也因此无法开始。建议今天先确定新节点，并由我负责每日跟进。”

CLOSE / 结尾

请示 + 表态 + 确认

“您看是否按这个方案调整？如果可以，我立即同步团队，明天上午反馈第一轮结果。”

BAD NEWS / 汇报坏消息

事实不绕，责任不躲，办法不少。

  1. 01先说已确认的事实和影响
  2. 02说明已经采取的措施
  3. 03提供方案、取舍与所需支持
  4. 04给出下一次反馈时间
