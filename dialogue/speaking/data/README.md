# 《像高手一样发言》结构化内容库

`book-content.json` 是“高手发言”网站后续扩充的单一内容源。

## 层级

- `chapters`：7 个一级工作场景。
- `sections`：21 个主要内容单元，与原书目录一一对应。
- `formulaIndex`：跨章节的口诀与公式索引。
- `sceneIndex`：从用户真实任务反查内容单元的场景索引。

## 单元字段

每个内容单元统一使用：

- `problem`：要解决的实际问题。
- `formula`：原书的公式、口诀或结构。
- `steps`：可执行步骤。
- `principles`：使用原则。
- `antiPatterns`：常见错误。
- `exampleTypes`：后续适合填充的案例类型。
- `related`：关联单元（可选）。

## 编辑原则

1. 保留作者命名的方法与精确结构。
2. 不存储原书长段文字，案例只作结构化改写。
3. 新页面优先读取此 JSON，不再在 JavaScript 中复制内容。
4. 新增单元必须使用稳定 ID，便于搜索、收藏和跨站关联。
