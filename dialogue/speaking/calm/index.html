CONTROL / 释放心理

不用等到不紧张，
也可以开始说。

紧张是身体面对压力时的普遍反应。目标不是把它彻底消灭，而是把过度紧张降到不影响表达的程度。

01 / UNDERSTAND THE GAP

紧张往往来自：
想要很多，却没有把握。

现场有重要人物、希望给人留下好印象、担心犯错，都会抬高心理需求。如果同时又不知道说什么、怎么说，两者落差就会放大紧张。

EXPECTATION / 需求

“我必须一次就让所有人认可。”

对结果的期待越绝对，自我监控就越强。

−
CONFIDENCE / 把握

“我还不知道第一句说什么。”

结构、材料和练习不足，让任务显得不可控。

= 紧张落差
USEFUL TENSION

适度紧张

让人更专注、更警觉，表明你重视听众和任务。

TOO MUCH

过度紧张

当它已经导致思维停滞、无法开口或无法完成正常表达，就需要采取控制措施。

02 / WRITE · REMEMBER · SPEAK

提高把握，
不是在脑中多想几遍。

写WRITE

写稿子，是为了理清思路

先完整写下想说的内容，确认观点、顺序和依据。

背REMEMBER

记提纲，不是逐字背全文

记住开场、主要节点和结尾，给自己留出口头表达空间。

说SPEAK

开口试讲，让书面语变成口头语

听见自己的声音，找到拗口、过长和不自然的地方。

按点准备 → 带点上场 → 逐点展开

准备得越好，临场就越不需要依赖逐字记忆。

03 / FOUR CONTROL METHODS

根据当时状态，
选一种最容易做的。

四种方法不是一次解决所有紧张的开关。它们的作用是帮你顺利进入表达，真正的稳定还来自反复练习。

04 / 30-SECOND RESET

轮到你之前，
先稳住三件事。

这个练习不追求完全放松，只帮你把注意力从“会不会失败”拉回“我现在要做什么”。

30SECONDS

准备开始

点击开始，先放松肩膀和下颚。

呼吸以舒适为准；如果出现不适，请立即停止。

YOUR ANCHOR

最后只记住一件事：
你的第一句是什么？
