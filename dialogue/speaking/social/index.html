01 / 2·3·1 INTRODUCTION

自我介绍，
不只是报出姓名。

一次有效的自我介绍，要让对方知道你是谁、你的特点是什么，以及你们之间可以建立怎样的联系。

2TWO IDEAS

两个基本思路

提供价值连接：我能为这段关系带来什么。
反映个人特质：我有什么真实、可记忆的特点。

3THREE DETAILS

三个表达细节

注意仪态、声音和目光；让名字更容易被记住；根据场合保持内容和时长得体。

1ONE PREMISE

一个基本前提

认识你自己。如果说不清自己擅长什么、在意什么，介绍就只能停留在单位和职务。

BEFORE / 无效介绍

“大家好，我叫小林，在市场部工作，很高兴认识大家。”

AFTER / 建立连接

“大家好，我是市场部的小林，主要做用户调研。如果大家想知道用户为什么在某一步放弃，可以来找我一起挖线索。”

02 / FIVE CHAT FORMULAS

没有话题时，
从眼前的信息开始。

五种公式对应不同的话题入口。点击切换，查看步骤、示例和使用边界。

03 / CHANNEL ETIQUETTE

换一种媒介，
表达也要换一种方式。

电话重及时互动，短信重完整告知，微信则要考虑对方是否方便查看、复读和处理。

COMPLETE CASES FROM THE BOOK

公式下面，
是原书怎样实际开口。

完整保留第七章的实际案例。点击分类筛选；较长对话可展开全文，方便对照每一步公式。

常见无效介绍问好 + 名字 + 客套

为什么听完记不住

“大家好！我叫××，初来乍到，请多关照！”
原书评价：形式普遍、拿来就能用，但内容过于简单，听众很难留下印象。
价值连接职业说精准

医生怎样介绍职业

如果只说自己是一名医生，还不够详细；如果说自己是一名儿科大夫，并进一步说明擅长的方向，就更精准。听众中初为父母的人更容易记住，因为这与他们的切身利益相关。

原书用这个例子说明：职业不是只报名称，还要说清能为别人提供什么价值。
个人特质传统相声贯口

真正有记忆点的爱好

作者的一位朋友喜欢背相声贯口，尤其是《八扇屏》《英雄论》《报菜名》《地理图》《白事会》《夸住宅》等传统老段子。一个人坐地铁时，别人都在玩手机，他却会独自念叨，有时还不小心背出声、手中比画。

与泛泛地说“喜欢读书、旅游、音乐”相比，这才是与众不同的个人特点。
名字记忆谐音法

刘芳：万古流芳

“我叫刘芳，人生在世定当创造价值，万古流芳。”
通过熟悉的词语建立谐音连接，让大家记住姓名的读音和含义。
名字记忆拆字法

王赟：文、武、贝

“赟”字比较生僻，上面是“斌”，下面是“贝”，寓意美好。介绍时可以把它拆成“文 + 武 + 贝”：不仅文武双全，还很有钱，就是现在常说的“高富帅”。

遇到生僻字，可用拆字法让别人既记住读音，也记住写法。
社交场合幽默谐音

宋德让：送了还得让

“一般人都愿意和我做生意。为什么呢？我这个人‘送（宋）了，还得（德）让’，大家绝对不会吃亏。”
原书用来说明：非正式社交场合可以用幽默诙谐的方法帮助记忆。
耳钉好看法 · 完整案例发现 + 赞美 + 请教

和领导乘车去调研

展开完整案例
作者的一位女同事小美，和单位女领导坐车去下乡调研。上车后，小美发现领导戴了新耳钉。她说：“啊，领导今天你戴的新耳钉，（发现）真漂亮，和你的发型特别搭，看起来优雅大方。（赞美）我也想去换个耳钉，但就是不知道该怎么挑，怎么配，您教教我吧！”（请教）一路上，两个人围绕耳钉的话题聊了半个小时。
原书案例保留；实际使用应确保赞美真实，并避开可能让对方不适的身体评价。
天气不错法 · 完整案例同意 + 重复 + 解释

上班路上碰见同事

展开完整案例
对方说：“今天天气真不错。”这时候，可以接话：“就是的，（同意）今天天气确实好，（重复）前两天雾霾太严重了，今天总算见到了太阳，空气也不错，温度也合适。”（解释）谈到这里，还可以继续从解释中寻找话题，比如接着聊雾霾，让聊天深入展开。
男女聊天法 · 完整案例细节 + 感受 + 描述

同事感冒了，怎样继续聊

展开完整案例

小王发现同事小美感冒了，过去表示关心。原先他只会说“感冒要多喝点水，多休息”，然后就没有然后了。

现在他可以说：“哎呀，小美，感冒啦？我前几天也感冒了，头疼，嗓子痒，浑身无力，也特别难受！”（细节 + 描述问题）

小美说：“就是的，头晕乎乎的，手上一堆活儿没法干了。”

小王接着说：“上次我在家，躺了好几天才缓过来。要多喝水，及时休息，尤其是晚上要早点睡觉，多出出汗能好得快些。”（在描述的前提下再具体化，让对方感受到诚意）

原书按性别解释这套方法；实际更适合把它理解为所有关系中的“具体倾听与情绪回应”。
好为人师法 · 完整案例赞美 + 请教 + 表态

从锻炼聊到项目执行

展开完整案例

一天，小张见到李主任，说：“李主任，您最近气色真不错，肚子也比原来小了，是不是一直在锻炼呢？（真诚地赞美）我爸也嚷嚷要减肥，就是减不下来。您能天天锻炼，有什么诀窍没？”（自然地请教）

李主任说：“哪有什么诀窍，就是坚持，我认准一件事就坚持到底，给自己定的目标就一定完成。”

小张说：“您说得真好，不光是锻炼身体，做任何事都得这样。前段时间，我们在推进××项目上有难度，今天听了您的话，我觉得下一步要在目标量化、任务管理等方面再下功夫。认准的事，就一定要想办法克服困难、坚持到底。”（表态，把话往工作上靠）

原书原例涉及身材评价；现实中应先判断熟悉程度，避免冒犯。
最近怎样法 · 完整案例提问 + 发现 + 提问

封闭问题为什么聊不下去

展开完整案例

小王在上班路上遇到好久不见的同学，问：“老同学，最近忙不？家里好吧？孩子上幼儿园了没有？”这些都是封闭式问题，对方通常只需回答“是”或“不是”，很快就会没话聊。

如果改成“最近工作怎么样？家里怎么样？孩子怎么样？”这些开放式问题，对方就需要阐述和解释，释放更多信息，双方也能从中找到感兴趣的话题继续交流。

电话前短信身份 + 事项 + 询问

先问是否方便通话

王处长，您好！我是××局办公室小孙，有件事我想给您电话汇报一下。不知道现在方便不？
春节短信 · 完整原文感谢 + 表态 + 祝福

给领导发节日信息

尊敬的王书记，过年好。我是办公室小李。感谢您在过去的一年里对我的关心和帮助，特别是在写材料方面，我从您身上学习到了很多东西。新的一年即将来临，我将继续全力以赴、努力工作，不辜负您的期望，祝愿单位在您的带领下工作再上一层楼，也祝愿您及家人新春快乐，阖家幸福。
原书提示：不要使用雷同群发内容；感谢、赞美和祝福要具体、真诚，并尽量错开发送高峰。
回复任务收到 + 行动 + 时间

不要只回复“收到”

领导：“小王，抓紧时间把材料写好交给我。”

“收到，我现在就写，明天上午一上班我就给您送办公室去。”
比单独回复“收到”多了立即行动和明确交付时间。
电话复述重要事项确认

确认自己理解正确

“您刚才说的这几点……不知道我理解得对不对？”
在对方交办事情后快速总结确认，既避免误解，也体现重视。
