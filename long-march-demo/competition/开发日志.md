# 开发日志

| 阶段 | 完成内容 | 代表性问题与解决办法 |
|---|---|---|
| 1 原型 | 首页、路线、六站框架 | 先建立移动端信息结构，再填充内容 |
| 2 内容 | 六站史实、因果链、关键词、30题 | 权威来源逐站标注，避免无出处材料 |
| 3 任务 | 六种智力任务、星级评分与顺序解锁 | 用因果排序、推理、拼图、计算、数独、配对表达不同历史选择 |
| 4 完整性 | 长征全景、四支队伍、会师关系、原创数字信息卡 | 不复制原海报设计，仅引用权威数据并标注统计口径与来源 |
| 5 史料 | 人物群像和史料阅读卡 | 不虚构引语，以简明转述配原始链接 |
| 6 趣味 | 随机情境、选择后果、任务星级 | 删除不参与规则的装饰性指标，让反馈与真实成绩对应 |
| 7 成长 | 盖章、精神徽章、精神行囊、挑战奖章 | 让站点任务、星级与最终荣誉形成学习闭环 |
| 8 路线 | 红线与六双逐渐磨损的草鞋站标 | 用草鞋变化表现长征路越走越艰难 |
| 9 适配 | 修复路线文字越界、遮挡和站点定位 | 边缘站点内向展开，保持红线和站标清楚 |
| 10 交付 | 答辩模式、版本说明、测试清单和迁移清单 | 明确Web原型与AIA/APK成品的边界 |
| 11 进阶 | 重写30道“十题远征”题库 | 去掉可凭常识排除的选项，加入材料、因果、排序、比较与迁移 |
| 12 线索 | 将关键词卡改为任务奖励式精神线索 | 用“历史证据—判断依据—今日行动”建立推导关系，完成任务后自动归档 |
| 13 辨析 | 增加六道精神辨析与个性化最终奖章 | 辨析通过后线索才进入精神行囊，最终奖章记录所选线索及今日行动 |
| 14 AIA同步 | 将最新网页、字体、兼容样式和ES5脚本全量打包 | 旧版WebView不支持部分新语法，用Babel和本地polyfill转换 |
| 15 阅读流程 | 六站四面板与上一页/下一页导航 | 在窄屏模拟器中减少跳转迷失，并修复封面序号 |
| 16 任务兼容 | 六种智力任务的触控、输入与反馈 | 放大触控区，避免数字键盘自动遮挡，统一空值检查 |
| 17 挑战闭环 | 错题专项、六站辨析、精神行囊与最终信息图 | 错题专项不计入百分制最高分，最终奖章需完成全部学习条件 |
| 18 验收 | 同步网页与AIA旧浏览器脚本，修正本地离线提示 | 静态检查与Windows 2019模拟器实测分开记录，不把未完成的实机验证标为通过 |

每次修改后均进行 JavaScript 语法检查、浏览器渲染检查、线上资源核对和 Git 版本提交。
