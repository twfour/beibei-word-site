# 开发日志

| 阶段 | 完成内容 | 代表性问题与解决办法 |
|---|---|---|
| 1 原型 | 首页、路线、六站框架 | 先建立移动端信息结构，再填充内容 |
| 2 内容 | 六站史实、因果链、关键词、30题 | 权威来源逐站标注，避免无出处材料 |
| 3 任务 | 六种任务与顺序解锁 | 用不同交互表达不同历史选择 |
| 4 完整性 | 长征全景、四支队伍、会师关系 | 明确六站不等于全部长征路线 |
| 5 史料 | 人物群像和史料阅读卡 | 不虚构引语，以简明转述配原始链接 |
| 6 趣味 | 行军指标、随机情境、选择后果 | 不用失败惩罚消解历史严肃性 |
| 7 成长 | 盖章、精神行囊、纪念卡 | 把六站连接成连续研学历程 |
| 8 思想 | 三层思考和一个月行动计划 | 从知识记忆推进到现实行动 |
| 9 适配 | 修复路线文字越界、遮挡红线 | 边缘站点内向展开，文字底板透明 |
| 10 交付 | 答辩模式、版本说明、迁移清单 | 明确Web原型与AIA/APK成品的边界 |

每次修改后均进行 JavaScript 语法检查、浏览器渲染检查、线上资源核对和 Git 版本提交。
