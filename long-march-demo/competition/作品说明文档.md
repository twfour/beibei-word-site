# 《长征研学·星火档案》作品说明

## 基本信息

- 参赛组别：初中组，个人作品
- 当前版本：1.0.0 Web 功能原型
- 待补充：学生姓名、学校、指导教师（如有）
- 最终交付：`aia`、`apk`、PDF说明文档、3分钟以内MP4演示视频

## 设计理念

作品面向初中生，把长征中的代表性历史节点组织成“背景—史实—人物—史料—因果—精神—任务—行动”的研学闭环。六站是便于学习的代表性节点，不等同于长征全部路线。

## 核心功能

1. 六站顺序解锁与路线研学。
2. 长征全景、人物群像、史料来源和三层思考。
3. 六种站点任务，以及信念、补给、团结三项行军指标。
4. 30道随机测验、错题重练、关键词收藏。
5. 完成盖章、精神行囊、行动计划和纪念卡。
6. 本机保存、离线缓存、声音开关和进度重置。

## 技术说明

当前原型使用 HTML、CSS、JavaScript 和浏览器本地存储实现。正式参赛版本需按组委会指定的 App Inventor Desktop 2019 环境迁移，重新实现页面、TinyDB数据、计时器和任务逻辑，并导出 AIA 与 APK。

## 原创与AI辅助说明

开发过程中使用AI辅助生成和调试代码、提出设计建议、整理结构及优化表达。参赛学生应对主题、资料、功能和最终呈现作出自己的选择，逐项理解、修改、测试代码，并在答辩中如实说明AI使用范围。

## 内容来源与隐私

历史内容参考中共中央党史和文献研究院、中华人民共和国国防部、人民网党史频道、中央网信办等公开资料，各站点列有链接。进度、成绩和感悟保存在本机，不收集姓名、学校、电话、定位等信息。
