# 《长征研学·星火档案》作品说明

## 基本信息

- 参赛组别：初中组，个人作品
- 当前版本：1.1.0 Web 功能原型
- 待补充：学生姓名、学校、指导教师（如有）
- 最终交付：`aia`、`apk`、PDF说明文档、3分钟以内MP4演示视频

## 设计理念

作品面向初中生，采用“历史档案研学＋任务驱动学习”的设计，把长征中的代表性事件组织成“了解背景—阅读史实—分析因果—完成任务—获得反馈”的学习过程。六站是便于学习的代表性节点，不等同于长征全部路线。

## 核心功能

1. 六站顺序解锁、红色路线与逐站磨损的草鞋站标。
2. 四支红军路线关系、自主设计的长征数字信息卡、人物群像、史料来源和三层思考。
3. 因果排序、逻辑推理、路线拼图、行军计算、行军数独、会师配对六种任务，并记录尝试次数与最佳星级。
4. 30道材料分析、因果判断、事件排序和比较迁移题，支持随机抽题、错题重练；每站任务完成后，自动归档“历史证据—判断依据—今日行动”精神线索，并通过情境辨析后组成精神行囊。
5. 任务星级、完成盖章、精神徽章、挑战奖章和最终“星火全章”；选满三条精神行囊是最高奖章条件之一，最终奖章呈现三条行动线索，并解锁“四路长征时间环”。
6. 本机保存、离线缓存、声音开关和进度重置。

## 技术说明

当前原型使用 HTML、CSS、JavaScript 和浏览器本地存储实现。正式参赛版本需按组委会指定的 App Inventor Desktop 2019 环境迁移，重新实现页面、TinyDB数据、计时器和任务逻辑，并导出 AIA 与 APK。

## 原创与AI辅助说明

开发过程中使用AI辅助生成和调试代码、提出设计建议、整理结构及优化表达。参赛学生应对主题、资料、功能和最终呈现作出自己的选择，逐项理解、修改、测试代码，并在答辩中如实说明AI使用范围。

## 内容来源与隐私

历史内容参考中共中央党史和文献研究院、中华人民共和国国防部、中国军网、人民网党史频道、中央网信办等公开资料，各站点列有链接。进度、成绩和收藏保存在本机，不收集姓名、学校、电话、定位等信息。“数字长征”信息卡由本作品重新设计，仅引用经核对的历史数据，并保留国防部原始资料链接和统计口径说明。
