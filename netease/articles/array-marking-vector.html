02 / FIVE LESSONS

五道题，四种
核心动作

桶计数

分数统计

把分数当作桶编号，桶里的数字就是人数。

int cnt[1010] = {}, n, m, t;
cin >> n >> m;
for(int i = 1; i <= n; i++){
    cin >> t;
    cnt[t]++;
}
for(int i = 0; i <= m; i++)
    cout << cnt[i] << " ";

关键cnt[t]++：用值作下标，对应计数加 1。

易错数组必须 = {} 清零；输出要写 i <= m，不能漏掉满分。

覆盖标记

区间覆盖长度

重叠位置只算一次，所以“标记为 1”，而不是反复累加。

int n, l, r, a[10010] = {};
cin >> n;
while(n--){
    cin >> l >> r;
    for(int i = l; i <= r; i++) a[i] = 1;
}
int cnt = 0;
for(int i = 0; i <= 10000; i++)
    if(a[i] == 1) cnt++;

关键a[i] = 1 表示位置已经覆盖，多次覆盖状态仍是 1。

易错不要直接相加各区间长度，否则重叠部分会被重复计算。

最小值追踪

小杨的智慧购物

每类文具只保留目前见过的最低价格。

int a[100010] = {}, m, n;
cin >> m >> n;
for(int i = 1; i <= n; i++){
    int k, p; cin >> k >> p;
    if(a[k] == 0 || a[k] > p) a[k] = p;
}
int sum = 0;
for(int i = 1; i <= m; i++) sum += a[i];

关键a[k] == 0 处理第一次遇到；之后只接受更低价格。

易错若只判断 a[k] > p，初值 0 永远不会被正价格更新。

字符计数

出现最多的字符

字符也能映射成下标；相同次数时，保留最后出现者。

int cnt[130] = {};
for(int i = 0; i < s.size(); i++)
    cnt[s[i]]++;
int maxn = -1e9; char res;
for(int i = 0; i < s.size(); i++){
    if(cnt[s[i]] >= maxn){
        maxn = cnt[s[i]]; res = s[i];
    }
}
int cnt[30] = {};
for(char ch : s) cnt[ch - 'a']++;
int maxx = 0; char ans;
for(char ch : s){
    if(cnt[ch - 'a'] >= maxx){
        maxx = cnt[ch - 'a']; ans = ch;
    }
}

关键>= 让后遇到的同频字符覆盖前者；> 则会保留第一个。

对比ASCII 写法更通用；ch-'a' 只适合纯小写字母，但更省空间。

动态收集

输出奇数

边读边筛选，把需要的结果按原顺序放进 vector。

vector<int> a;
for(int i = 0; i < n; i++){
    cin >> t;
    if(t % 2 != 0) a.push_back(t);
}
bool first = true;
for(int x : a){
    if(!first) cout << ",";
    cout << x; first = false;
}

关键push_back 动态追加；first 避免首尾多出逗号。

易错判断奇数用 t % 2 != 0，才能正确包含负奇数。
