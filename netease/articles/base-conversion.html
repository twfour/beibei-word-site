02 / THREE METHODS

三条转换路线，
方向决定算法

十进制整数 → k 进制

除 k 倒取余

每次余数都是当前最低位，所以记录顺序与最终书写顺序相反。

199 ÷ 8商 24余 7
24 ÷ 8商 3余 0
3 ÷ 8商 0余 3

余数从下往上读：307₈

while (n) {
    a[++idx] = n % r;  // 先取最低位
    n /= r;            // 再去掉最低位
}
for (int i = idx; i >= 1; i--)
    cout << digit(a[i]);

方向余数是低位先出现，因此必须倒序输出。

边界n=0 时循环不会执行，要单独输出 0。

十进制小数 → k 进制

乘 k 正取整

每次得到的是小数点后从左到右的下一位，因此按产生顺序读取。

0.375 × 20.75取整 0
0.75 × 21.5取整 1
0.5 × 21.0取整 1

整数部分从上往下读：0.011₂

为什么 0.1 难以精确存储？

0.1 × 2 的小数部分会循环，二进制表示成为无限循环小数。计算机只能截断到有限位，因此保存的是近似值。

区别整数部分“除基取余、逆序”，小数部分“乘基取整、正序”。

停止小数归零或达到题目规定精度。

k 进制 → 十进制

按权展开

整数位权从右向左是 k⁰、k¹、k²；小数点右边则是 k⁻¹、k⁻²。

101.11₂1×2² + 0×2¹ + 1×2⁰ + 1×2⁻¹ + 1×2⁻²5.75₁₀

506.2₈5×8² + 0×8¹ + 6×8⁰ + 2×8⁻¹326.25₁₀

10.C₁₆1×16¹ + 0×16⁰ + 12×16⁻¹16.75₁₀

long long ans = 0, p = 1;
for (int i = s.size() - 1; i >= 0; i--) {
    int value = isupper(s[i])
        ? s[i] - 'A' + 10 : s[i] - '0';
    ans += value * p;
    p *= k;
}

字符映射'7'-'0'=7，'C'-'A'+10=12。

位权p 从 1 开始，每向左一位乘一次 k。
