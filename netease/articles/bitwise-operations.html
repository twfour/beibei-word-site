02 / SIX OPERATORS

六种运算，都是
逐位发生

&

按位与

两位都是 1 才得 1。

10101100
& 01101010
= 00101000172 & 106 = 40
|

按位或

至少一位是 1 就得 1。

10101100
| 01101010
= 11101110172 | 106 = 238
^

按位异或

相同为 0，不同为 1。

10101100
^ 01101010
= 11000110172 ^ 106 = 198
~

按位取反

每一位 0、1 互换，包括符号位。

~10101100
= 010100118 位示意：83
<<

左移

整体向左，右边补 0。

00001011 << 2
= 0010110011 × 2² = 44
>>

右移

无符号数补 0；有符号数通常补符号位。

00001011 >> 2
= 0000001011 ÷ 2² = 2
移位边界

左移可能溢出并改变符号位；负数右移是算术右移，资料示例中 −11 >> 2 = −3。处理纯位模式时优先考虑 unsigned。

04 / BIT TRICKS

一行表达式，
完成一次精准操作

01 / 清零

x & ~x

x 与自己的反码每一位都相反，因此结果永远为 0。

02 / 判断奇偶

x & 1

最低位为 1 是奇数，为 0 是偶数。

03 / 异或还原

x ^ b ^ b = x

b ^ b = 0，再利用 x ^ 0 = x。

04 / 交换变量

a^=b; b^=a; a^=b;

无需临时变量，但资料也提醒实际代码中可读性较差。

05 / lowbit

x & -x

留下最低位的 1 以及它右侧的所有 0。20 的二进制是 10100，结果为 4。

06 / 消去最低位 1

x & (x - 1)

每执行一次少一个 1；循环次数就是二进制中 1 的个数。

07 / 取第 i 位

(x >> i) & 1

先把第 i 位移到最右，再只保留最低位。

08 / 取相反数

-x = ~x + 1

补码机制的直接结果；所以 ~1 = -2。

05 / CODE APPLICATIONS

课堂代码中的
三次组合运用

输出 32 位补码
for(int i = 31; i >= 0; i--)
    cout << ((n >> i) & 1);

从第 31 位到第 0 位逐位提取；负数前面会出现连续的 1。

高低 16 位交换
unsigned int n;
cout << ((n >> 16) + (n << 16));

右移让高 16 位落到低位，左移让低 16 位升到高位；两部分互不重叠。

统计二进制中的 1
while(x){
    x &= x - 1;
    cnt++;
}

13：1101 → 1100 → 1000 → 0000，共消去 3 个 1。
