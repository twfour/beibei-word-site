00 / 使用原则

看见事实，
容纳解释，
等待证据。

01

状态不等于人格

一次沉默可能来自疲劳、陌生、疼痛或谨慎。先描述当下，暂不定义整个人。

02

变化比姿势重要

摸鼻子没有固定含义；相较个人基线突然增加的动作，才值得进一步观察。

03

判断必须能被推翻

写下预测和期限。若现实不支持，就降低置信度或放弃原假设。

01 / BASIC 方法

五步，把直觉变成证据

每一步都在减少一种常见误判。

B
BASELINE / 基线

先知道他平常怎样

语速、眼神、坐姿、小动作都因人而异。没有个人基线，单个动作几乎无法解释。

避免“动作字典”
A
ANTECEDENT / 前因

行为之前，发生了什么

记录触发事件：被追问、换了对象、时间临近，还是环境变冷。情境决定含义。

避免脱离语境
S
SIGNAL CLUSTER / 线索组

至少三个方向一致的变化

语言、声音、身体三类线索共同变化，才形成一个值得验证的假设。

避免单点定性
I
ITERATION / 重复

三次观察，三种场景

只在压力场景出现的是状态；跨场景反复出现，才可能接近稳定习惯。

避免以偏概全
C
CHECK / 校准

用后续行为检验预测

真实行为优先于本人解释，长期记录优先于第一印象。错了，就更新。

避免确认偏误
02 / 线索边界

什么能看，什么不能猜

把旧式“识人术”改造成现代观察。

眼神与表情STATE

适合观察

兴趣、迟疑、疲劳、疼痛，以及谈到某个话题时的突然变化。

不能断定

忠诚、智商、撒谎或道德品质。

姿态与距离CONTEXT

适合观察

参与度、身体朝向、空间偏好、是否准备结束互动。

不能断定

双臂交叉就是拒绝，摸鼻子就是心虚。

声音与语言DYNAMIC

适合观察

相较基线的语速、音量、停顿、修改措辞和回应延迟。

不能断定

声音好听就可信，声调低沉就有支配力。

服装与物品DISPLAY

适合观察

场合意识、自我呈现、准备程度与长期稳定的选择偏好。

不能断定

感情经历、道德水平或婚姻倾向。

笔迹与手部MOTOR

适合观察

与本人过去相比的震颤、无力、速度和运动控制变化。

不能断定

人格、财富、命运或疾病诊断。

医学边界
身体异常只能提示“需要关注”，不能代替专业诊断。

突然出现的步态、声音、脸色或书写变化持续存在时，应建议就医，而不是自行解释。

04 / 14天实验
14

天校准
你的判断

目标不是证明自己“会看人”，而是发现自己在哪些情境下容易看错。

  1. 第1—2天只选三个维度

    例如主动性、谨慎程度、压力下的沟通方式。

  2. 第3—5天定义可见行为

    把“谨慎”写成询问信息、检查细节、准备备选方案。

  3. 第6—10天预先写下预测

    结果发生之前记录，防止事后把任何结果都解释成“我早知道”。

  4. 第11—13天寻找反例

    主动记录没看准的时刻；反例比印证更能提高判断质量。

  5. 第14天复盘命中率

    正确1分，部分正确0.5分，错误0分，无法验证不计分。

最后的问题不是

“我看穿他了吗？”

而是

“什么证据会让我改变看法？”
