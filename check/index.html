00 / 使用原则

看见事实，
容纳解释，
等待证据。

01

状态不等于人格

一次沉默可能来自疲劳、陌生、疼痛或谨慎。先描述当下，暂不定义整个人。

02

变化比姿势重要

摸鼻子没有固定含义；相较个人基线突然增加的动作，才值得进一步观察。

03

判断必须能被推翻

写下预测和期限。若现实不支持，就降低置信度或放弃原假设。

01 / BASIC 方法

五步，把直觉变成证据

每一步都在减少一种常见误判。

B
BASELINE / 基线

先知道他平常怎样

语速、眼神、坐姿、小动作都因人而异。没有个人基线，单个动作几乎无法解释。

避免“动作字典”
A
ANTECEDENT / 前因

行为之前，发生了什么

记录触发事件：被追问、换了对象、时间临近，还是环境变冷。情境决定含义。

避免脱离语境
S
SIGNAL CLUSTER / 线索组

至少三个方向一致的变化

语言、声音、身体三类线索共同变化，才形成一个值得验证的假设。

避免单点定性
I
ITERATION / 重复

三次观察，三种场景

只在压力场景出现的是状态；跨场景反复出现，才可能接近稳定习惯。

避免以偏概全
C
CHECK / 校准

用后续行为检验预测

真实行为优先于本人解释，长期记录优先于第一印象。错了，就更新。

避免确认偏误
02 / 线索边界

什么能看，什么不能猜

把旧式“识人术”改造成现代观察。

眼神与表情STATE

适合观察

兴趣、迟疑、疲劳、疼痛，以及谈到某个话题时的突然变化。

不能断定

忠诚、智商、撒谎或道德品质。

姿态与距离CONTEXT

适合观察

参与度、身体朝向、空间偏好、是否准备结束互动。

不能断定

双臂交叉就是拒绝，摸鼻子就是心虚。

声音与语言DYNAMIC

适合观察

相较基线的语速、音量、停顿、修改措辞和回应延迟。

不能断定

声音好听就可信，声调低沉就有支配力。

服装与物品DISPLAY

适合观察

场合意识、自我呈现、准备程度与长期稳定的选择偏好。

不能断定

感情经历、道德水平或婚姻倾向。

笔迹与手部MOTOR

适合观察

与本人过去相比的震颤、无力、速度和运动控制变化。

不能断定

人格、财富、命运或疾病诊断。

医学边界
身体异常只能提示“需要关注”，不能代替专业诊断。

突然出现的步态、声音、脸色或书写变化持续存在时，应建议就医，而不是自行解释。

03 / 原书方法的现代转译

九种现场观察法

保留原书的具体看法，但不把它们当结论。每一项都改造成“看什么—可能说明什么—怎样验证”。

原书线索现代转译验证动作
01
眼神与眼睑观察兴趣、负荷与不适
最适合观察“变化”

原书怎样看

眼神清亮被视为精神充足；目光游移、低垂、频繁眨眼或两眼状态不同，被联系到性格、心事与健康。

现在怎样用

只比较个人基线：谈到某个主题后，凝视时间、眨眼、瞳孔朝向或眼睑紧张是否突然改变。它提示认知负荷、兴趣或不适，不证明撒谎。

怎样验证

换成中性问题，看眼神是否恢复；稍后用开放式提问确认：“这个部分是不是还有顾虑？”

可记录：提到预算时，原本稳定的目光转向桌面，停顿增至约4秒；换到进度话题后恢复。

02
坐姿与空间距离观察参与、戒备与关系位置
第三章的核心方法

原书怎样看

深坐、浅坐、跷腿、托腮、两腿开合，以及恋人并坐时身体倾斜方向，都被用来判断个性和亲密程度。

现在怎样用

观察“朝向、距离、开放度”三件事：身体是否朝向谈话对象，是否主动缩短距离，姿态在何时从放松转为收紧。

怎样验证

改变话题或座位条件。如果身体只在某一话题后退，可能是内容不适；若始终远离，也可能只是个人空间偏好。

组合信号：身体后倾＋双脚转向出口＋回答变短，比单独“双臂交叉”更值得注意。

03
步态与鞋底观察节奏、负荷与身体偏侧
先看身体，后谈性格

原书怎样看

脚步有力、拖步、步态柔弱以及鞋底不同位置的磨损，被联系到积极性、急躁、器官健康和饮食偏好。

现在怎样用

步速能提示当下节奏；左右摆动、拖步、单侧磨损更适合用于发现受力、鞋履或关节问题。不能由鞋底判断酒量或品德。

怎样验证

比较不同鞋、不同路面和疲劳前后；持续偏侧、疼痛或步态突然改变，应建议专业评估。

可预测：若“急促步态”来自赶时间，任务结束后应恢复；若跨场景持续，才考虑它是稳定节奏。

04
握手与手部动作观察互动风格与紧张调节
看双方，不看单方

原书怎样看

握力、主动伸手、手掌方向被用来判断自信和支配；揉手、扯头发、摸喉咙、咬笔等被视为焦虑表现。

现在怎样用

握手受文化、职位、伤病影响。重复的自我触摸更适合解释为“可能在调节紧张”，尤其当它紧随困难问题出现时。

怎样验证

先统计平静话题下的动作频率，再比较压力话题；询问是否需要时间、资料或休息，看动作是否减少。

不要写：“摸脖子＝撒谎。”　改写：“回答责任归属时首次连续摸颈部三次。”

05
声音与说话方式观察信心、情绪与信息把握度
第四章最实用部分

原书怎样看

声调平稳被视为正直；声音弱、语尾不清被视为胆小；语气冲、大声被视为反抗；声音有力被视为勇敢。

现在怎样用

记录相对变化：音量、音高、语速、停顿、语尾、修改次数。声音首先反映当时情绪与自我呈现，不等于真实人格。

怎样验证

让对方分别讲熟悉和陌生主题。如果只在陌生主题含糊，可能是信息不足；若面对权威才降低音量，则与关系情境有关。

实用组合：停顿增加＋语尾变轻＋反复限定“应该、可能”，可提出“把握不足”的假设。

06
服饰与随身物品观察自我呈现与场合策略
不是道德测验

原书怎样看

服装颜色、款式、手提包、皮带等被解释为欲望、独立性、婚恋态度和女性性格。

现在怎样用

观察穿着是否服务于场合、舒适、身份或独特性，以及长期是否稳定。它更接近“希望怎样被看见”，不是内心真相。

怎样验证

比较工作、休闲、正式活动三个场景；询问选择理由。若跨场景始终强调功能性，才能提出“实用导向”的假设。

可问：“你选这件衣服最看重什么？”答案通常比旁观者的象征解读更可靠。

07
睡姿观察舒适需求与身体状况
不用于窥探亲密关系

原书怎样看

仰卧、俯卧、蜷缩、抱枕、夫妻相拥或背对背，被联系到性格、安全感、欲望和婚姻质量。

现在怎样用

睡姿更常受温度、床铺、呼吸、疼痛、孕期和习惯影响。频繁翻身、突然改变或固定偏侧可作为睡眠质量线索。

怎样验证

连续记录7晚，同时记录温度、饮酒、疼痛、入睡时间和醒后精神；寻找共同变化，而非解释单晚姿势。

有用问题：“这种姿势是否让你更舒服？”而不是“这种姿势说明你缺乏安全感。”

08
脸色、嘴唇与头发观察健康变化
只作提醒，不作诊断

原书怎样看

面部光泽、血色、唇色、眼白和头发变化被用来判断健康，部分内容又延伸到运势与性格。

现在怎样用

重点看“突然、持续、伴随症状”：异常苍白、发紫、黄染、脱发或表情迟钝值得关注；光线和化妆会严重干扰观察。

怎样验证

在自然光下复看，询问是否疲劳或不适；持续异常交给医生和检查数据，不作疾病名称推断。

红旗：突然口角歪斜、言语不清、单侧无力属于急症信号，应立即求助。

09
笔迹观察运动状态与任务方式
比较本人前后

原书怎样看

字的大小、方圆、倾斜、笔压、速度和结构被用来判断果断、谨慎、聪明、财富与命运。

现在怎样用

笔迹适合看同一个人的变化：震颤、笔压、速度、行距、遗漏和布局，可能受到疲劳、情绪、药物或运动控制影响。

怎样验证

用相同纸笔、相同文本，在不同时间重复书写；先排除工具和速度要求，再考虑是否需要健康评估。

不能用于：招聘筛选、人格定性、判断诚信，以及预测婚姻和命运。

现场口诀先基线→找触发→看组合→留替代→做预测

05 / 14天实验
14

天校准
你的判断

目标不是证明自己“会看人”，而是发现自己在哪些情境下容易看错。

  1. 第1—2天只选三个维度

    例如主动性、谨慎程度、压力下的沟通方式。

  2. 第3—5天定义可见行为

    把“谨慎”写成询问信息、检查细节、准备备选方案。

  3. 第6—10天预先写下预测

    结果发生之前记录，防止事后把任何结果都解释成“我早知道”。

  4. 第11—13天寻找反例

    主动记录没看准的时刻；反例比印证更能提高判断质量。

  5. 第14天复盘命中率

    正确1分，部分正确0.5分，错误0分，无法验证不计分。

最后的问题不是

“我看穿他了吗？”

而是

“什么证据会让我改变看法？”
